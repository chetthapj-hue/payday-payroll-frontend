# PayDay Frontend MVP

คู่มือระบบบัญชีและสิทธิ์: [Backend AUTH.md](../payday-payroll/server/AUTH.md) และ [ผลทดสอบล็อกอิน](AUTH_TESTING.md)

React + Vite + Tailwind CSS สำหรับใช้งานบนเครื่องกับ Backend `~/Developer/payday-payroll/server` และ PostgreSQL `payday_db`

## เปิดใช้งาน

Terminal 1:

```sh
cd ~/Developer/payday-payroll/server
npm ci
# DATABASE_URL อยู่ใน server/.env เท่านั้น
npm run migrate
npm run create-admin -- --username myadmin  # ครั้งแรกเท่านั้น ตั้งรหัสเองแบบซ่อน
npm start
```

Terminal 2:

```sh
cd ~/Developer/payday-payroll-frontend
npm ci
npm run dev -- --host 127.0.0.1
```

เปิด URL Local ที่ Vite แสดง (ปกติ http://127.0.0.1:5173) Frontend เรียก `/api` ผ่าน Vite proxy ไปยัง http://127.0.0.1:3000 ไม่ต้องกำหนดบัญชีฐานข้อมูลใน Frontend

## ทำงานผ่านหน้าเว็บ

เข้าสู่ระบบโดยเลือกประเภทบัญชี **ผู้ดูแลระบบ** ด้วยบัญชีที่สร้างจากคำสั่งก่อนเริ่มงาน

1. **พนักงาน:** เพิ่มรายวันหรือรายเดือน แล้วรายการเรียงตามรหัสทันที ปุ่มแก้ไขใช้ API เดิม รหัสซ้ำมีข้อความภาษาไทย
2. **บันทึกการทำงาน:** เลือกพนักงาน วันที่ กะ และชั่วโมง OT รวม/OT 3 เท่า (รองรับทศนิยม) เวลาปกติล็อกไว้ 8 ชม. แปลงเป็นนาทีเต็มก่อนส่ง API ค่าอาหารถูกคำนวณตามกติกา 83/166 บาทจาก Backend แสดงรายการล่าสุด 100 แถว
3. **คำนวณเงินเดือน:** เลือกเดือนจ่าย กดคำนวณ แสดงรอบค่าจ้าง/อาหาร/กะและรอบ OT แยกกัน พร้อมยอดรายคนแต่ละองค์ประกอบ ตรวจยอดก่อนกดบันทึก
4. **รายงานที่บันทึก:** เปิดงวดเดิมได้หลัง reload ยอด ชื่อ รหัส ประเภท และอัตราที่ใช้คงเดิมแม้แก้พนักงานหรือลงเวลาเพิ่ม

ถ้างวดนั้นบันทึกแล้ว การเลือกเดือนเดิมเปิดรายงานเดิม การคำนวณไม่เขียนทับงวดที่บันทึกแล้ว

ตัวอย่างเดือน `2026-11` (พฤศจิกายน 2569): จ่าย 25 พฤศจิกายน 2569 รอบค่าจ้าง 17 ตุลาคม–16 พฤศจิกายน และรอบ OT 1–31 ตุลาคม รวมวันขอบทั้งสองวัน ค่าอาหารเก็บส่วนเพิ่ม OT ไว้แล้วจึงไม่บวก 83 บาทซ้ำ

## บัญชีพนักงาน

ในเมนูพนักงาน ส่วน **บัญชีเข้าสู่ระบบพนักงาน** เลือกพนักงาน ตั้งรหัสผ่านชั่วคราว 4–128 ตัวอักษร แล้วกดสร้างบัญชี พนักงานใช้รหัสพนักงานและรหัสผ่านนี้เข้าสู่ระบบ และต้องเปลี่ยนรหัสก่อนดูข้อมูล ผู้ดูแลรีเซ็ตรหัสหรือปิดบัญชีได้จากส่วนเดียวกัน

หลังบันทึกเงินเดือน กด **เผยแพร่งวด** เพื่อให้พนักงานเห็นยอด พนักงานมีหน้า **ประวัติการทำงาน** ที่กรองตามเดือน และ **เงินเดือนของฉัน** ซึ่งเห็นเฉพาะยอดที่บันทึกและเผยแพร่ของตัวเอง การบังคับสิทธิ์อยู่ที่ Backend ทุก API

## ตรวจโค้ดและทดสอบ

```sh
npm run lint
npm run build
```

วิธีสร้างฐานทดสอบ รัน Backend tests และ Chrome end-to-end อยู่ใน `../payday-payroll/server/README.md` ผลตรวจจริงอยู่ใน [TESTING.md](TESTING.md)

ทดสอบ Frontend กับ Backend ฐานทดสอบพอร์ตอื่นได้โดยไม่เปลี่ยนค่าปกติ:

```sh
PAYDAY_API_TARGET=http://127.0.0.1:3001 npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

`npm run build` สร้างไฟล์ใน dist สำหรับตรวจ production build การใช้งาน `/api` ในเครื่องตามคู่มือนี้ให้ใช้ Vite dev server; ถ้าจะนำ dist ไปให้ static server อื่น ต้องตั้ง reverse proxy `/api` ที่ server นั้นด้วย

## ลบหรือปิดสถานะพนักงาน

ในเมนู **พนักงาน** กด **ลบพนักงาน** ที่แถว จะมีหน้าต่างยืนยันพร้อมชื่อและรหัส ระบบตรวจบัญชี ประวัติงาน และรายการเงินเดือนที่ Backend อีกครั้งก่อนลบ พนักงานที่ไม่เคยมีข้อมูลเหล่านี้ลบได้ถาวร ถ้ามีข้อมูลจะเสนอ **ปิดสถานะพนักงาน** แทน โดยเก็บข้อมูลเดิมทั้งหมด ปิดบัญชีและยกเลิก session รวมทั้งซ่อนจากตัวเลือกลงเวลางานใหม่

ค้นชื่อ/รหัสในหน้าพนักงานได้รวมผู้ที่ปิดสถานะ หรือไป **บันทึกการทำงาน** ส่วน **ค้นประวัติ** เลือกพนักงานและเดือนเพื่อเปิดดูงานเก่า รายงานงวดเดิมเปิดได้จากเมนูรายงานตามปกติ การปิดสถานะไม่เปลี่ยนสูตรคำนวณหรือยอดงวดเดิม

Backend ที่ติดตั้งจากโค้ดเดิมให้รัน `npm run migrate` ใน `~/Developer/payday-payroll/server` ก่อนเปิด `npm start` เพื่อเพิ่มคอลัมน์สถานะ โดยไม่ลบข้อมูลเดิม

## พนักงานลงเวลาตนเองและรายได้สะสม

ล็อกอินเป็นพนักงานที่เปลี่ยนรหัสชั่วคราวแล้ว เลือก **ลงเวลาทำงาน** วันที่เริ่มต้นเป็นวันนี้ตามประเทศไทย เลือกย้อนหลังได้ ห้ามอนาคต เวลาปกติ 8 ชม. เลือกกะและกรอกชั่วโมง OT แล้วกด **บันทึกเวลาของฉัน** ประวัติและยอดสะสมอัปเดตทันที

ดูยอดใต้ฟอร์มหรือเมนู **รายได้สะสมของฉัน** เลือกเดือนจ่าย หน้าจะแสดงรอบค่าจ้าง 17–16 และรอบ OT เดือนก่อนแยกกัน พร้อมจำนวนวันที่ลงงานและรายได้แต่ละส่วน มีป้าย “ยอดสะสมก่อนปิดงวด” ส่วนยอดจริงที่เผยแพร่แล้วให้ดู **เงินเดือนของฉัน** ซึ่งไม่เปลี่ยนตามการลงเวลาเพิ่ม

รายเดือนยังใช้เต็มอัตราตามสูตร Admin เดิม ไม่เฉลี่ยตามจำนวนวันที่ลงงาน รายละเอียดและชุดทดสอบอยู่ใน `../payday-payroll/server/SELF_SERVICE.md`
